# CCNA Enterprise Network Project

A three-branch enterprise network implemented in Cisco Packet Tracer as a CCNA final project.

## Project Overview

The network consists of three interconnected branches, with each branch using a different dynamic routing protocol:

- **Branch 1:** EIGRP (AS 100)
- **Branch 2:** RIP v2
- **Branch 3:** OSPF (Area 0)

Route redistribution was configured between the different routing domains to enable communication across the branches.

## Technologies Used

### Routing

- Route Redistribution

### Switching
- VLANs
- VTP
- EtherChannel
- STP / RSTP
- SVI
- HSRP
- DHCP
- Router-on-a-Stick
